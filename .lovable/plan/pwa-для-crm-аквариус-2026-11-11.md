# PWA для CRM Аквариус

## Что получится
- Приложение устанавливается только с `crm.aquariuswash.ru`. При открытии — экран входа, затем CRM. Публичный сайт в приложении не открывается.
- Иконка приложения: наша лаймовая машинка, под ней надпись **CRM**. Это отдельные файлы; текущий значок сайта (favicon) не меняется.
- Уведомления обеим ролям (владелец и администратор), на каждом устройстве, где включены:
  1. **Новая запись** — сразу после создания записи (с сайта или из CRM): дата, время, авто, комплекс.
  2. **Подтвердите запись** — за 20 минут до начала, только для неподтверждённых записей.
- Вход сохраняется на год (сейчас 30 дней).
- Колокольчик в правом верхнем углу станет кнопкой «Включить уведомления» / показателем, что они включены.

## Ограничения
- В окне предпросмотра Lovable уведомления и установка не работают — только на `crm.aquariuswash.ru`.
- iPhone: уведомления приходят только если CRM добавлена на экран «Домой» (iOS 16.4+).
- Офлайн-режим не делаем.

## Технические детали
- Иконки: `public/crm-icon-192.png`, `crm-icon-512.png`, `crm-icon-maskable-512.png`, `crm-apple-touch-icon.png` (генерируются из маскота + текст CRM). `favicon.png` и `apple-touch-icon.png` не трогаем.
- `public/crm.webmanifest` (`start_url: "/"`, `scope: "/"`, `display: standalone`); ссылка на манифест и CRM-иконки добавляется в head только на CRM-хосте/маршруте `/admin`.
- Push без Firebase: стандартный Web Push (VAPID) с нашего Bun-сервера, библиотека `web-push`. Ключи VAPID — в env сервера.
- `public/push-sw.js` — только обработка push и клика по уведомлению (открывает CRM на нужной записи), без кэширования. Регистрируется только на `crm.aquariuswash.ru`, не в предпросмотре.
- Миграция `004_push.sql`: таблица `push_subscriptions` (user_id, endpoint, ключи) и поле `reminder_sent_at` у записей.
- API: `GET /api/v1/crm/push/key`, `POST/DELETE /api/v1/crm/push/subscribe` (проверка сессии).
- Отправка «новая запись» после успешного создания записи; планировщик раз в минуту ищет неподтверждённые записи, начинающиеся через ≤20 минут, без `reminder_sent_at`. Мёртвые подписки (404/410) удаляются.
- `SESSION_DAYS = 365`.
- Тесты: выбор записей для напоминания за 20 минут (подтверждённые и уже напомненные не попадают), срок сессии 365 дней.
- Деплой: `bun add web-push` в server, сгенерировать VAPID-ключи, добавить в env, применить миграцию.
